# v1.5.0

Date (UTC): 2026-02-25
Tag: `v1.5.0`

## Summary

- Expanded official architecture coverage with new adapter families and model matrix validation.
- Decoupled backend projection/gradient semantics into adapter-owned operators.
- Hardened route/smoke scripts for larger multimodal coverage and loader compatibility.

## Breaking Changes

- None (public API surface remains compatible).

## Features

- Added adapter families:
  - `gemma_like`
  - `phi_like`
- Expanded official catalog coverage (text + multimodal), including:
  - `tiiuae/falcon-rw-1b`
  - `google/gemma-2-2b`
  - `microsoft/phi-2`
  - `microsoft/Phi-3-mini-4k-instruct`
  - `HuggingFaceTB/SmolVLM-Instruct`
  - `Qwen/Qwen2-Audio-7B`
  - `HuggingFaceM4/idefics2-8b`
- Added backend operator layer:
  - `ProjectionAttentionOperator`
  - adapter-owned `attention_operator(...)` contract
- Added support in route/smoke model loading for:
  - `Qwen2AudioForConditionalGeneration`
- Added one-click model download helper:
  - `scripts/download_hf_models.py`

## Fixes

- `AttributionModel.from_pretrained(...)` now tries:
  - `AutoModel`
  - then `AutoModelForCausalLM` fallback
- HF backend config normalization now supports config fields:
  - `d_model`
  - `n_layers`
  - `n_heads`
- `scripts/test_text_vendor_parity.py` improvements:
  - HF-only fallback for non-TLens models
  - generic record fallback for tokenizer edge cases
  - known OPT runtime issue downgraded to explicit `skip` classification

## Compatibility

- Python: `>=3.10,<3.13`
- torch: `>=2.1`
- transformers: `>=4.49`
- transformer-lens: `>=2.11`

## Known Limits

- Multimodal attribution remains language-trunk centric.
- Text parity for `facebook/opt-125m` currently reports method-level `skip` with:
  - `known parity runtime limit: size mismatch in projection runtime`
  - tracked as backend parity follow-up.

## Upgrade Notes

- Core user flow remains:
  1. `model -> language trunk/graph`
  2. `prepared inputs -> attribution`
- Core defaults in matrix scripts now use `tier=core`; heavier/gated models remain available via explicit model lists or nightly tier.
